# Ampache API 5 sample responses

The XML files in this directory are official Ampache API 5 sample responses. They are used
only as fixtures for the JVM unit tests of the XML parsers and DTO mappers in
`app/src/test/java/com/amperfy/data/remote/ampache/` and
`app/src/test/java/com/amperfy/data/repository/ampache/`.

## Source

- https://github.com/ampache/python3-ampache (API 5 documentation samples)
- https://github.com/ampache/ampache (API documentation)

The files are used as published; they have not been edited for this project.
